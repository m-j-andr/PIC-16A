## A diagram involving class objects and instance objects

Consider the following code.

```python
class C:
    class_var = 0

    def __init__(self, i):
        self.instance_var = i

    def method(self, p1, p2):
        print(self.__class__.class_var)
        print(self.instance_var)
        print(p1, p2)

instance_1 = C(11)
instance_2 = C(22)
```

Here, I record a diagram for this code.

In case a concrete example is more helpful,
consider the following code.

```python
class Human:
    chromosomes = 46

    def __init__(self, age, height):
        self.age = age
        self.height = height

    def get_height(self):
        return self.height

yuki = Human(25, 159)      # yuki tsunoda
kristaps = Human(30, 218)  # kristaps porziņģis
```
